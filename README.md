## 🍽️ Recipe Finder Application

###  Overview
- Recipe search app using TheMealDB API
- Helps users find meals with details instantly

###  Features
- Search recipes by name
- View ingredients and cooking instructions
- Display meal images
- Handles empty or invalid searches

###  Tech Stack
- HTML
- CSS
- JavaScript
- REST API (TheMealDB)

###  Functionality
- Fetch data from API
- Render results dynamically on UI
- Uses async/await for handling requests

###  Learning
- API integration
- Async JavaScript
- DOM manipulation
- Error handling
